# Развёртывание на Render

API и интерфейс продавца работают в одном Node web service. PostgreSQL находится в том же регионе Frankfurt. Vercel и Supabase не требуются.

`render.yaml` описывает инфраструктуру для нового окружения. Для уже созданных сервисов используйте их текущие настройки, чтобы не создавать повторную базу.

Сборка: `npm ci --include=dev && npm run build && npm prune --omit=dev`.
Запуск: `bash scripts/render-start.sh`. Запуск применяет миграции, создаёт первого владельца при пустой базе и запускает API, который также отдаёт собранный интерфейс.

Переменные Render:

| Переменная               | Значение                                                                                              |
| ------------------------ | ----------------------------------------------------------------------------------------------------- |
| NODE_ENV                 | production                                                                                            |
| NODE_VERSION             | 24.19.0                                                                                               |
| DATABASE_URL             | Internal Database URL собственной базы MyStore                                                        |
| SESSION_SECRET           | Случайный секрет минимум 32 символа                                                                   |
| BOOTSTRAP_OWNER_EMAIL    | Логин первого владельца, по умолчанию admin@mystore.test                                              |
| BOOTSTRAP_OWNER_PASSWORD | Случайный пароль минимум 16 символов                                                                  |
| BOOTSTRAP_SHOP_NAME      | MyStore                                                                                               |
| WEB_ORIGINS              | Необязательно: точные разрешённые адреса через запятую; без значения используется RENDER_EXTERNAL_URL |

Первый вход: `/seller`, email и пароль из переменных BOOTSTRAP_OWNER. Повторный запуск не меняет пароль и не добавляет владельца в существующую базу. После сохранения пароля можно удалить обе переменные BOOTSTRAP_OWNER_EMAIL и BOOTSTRAP_OWNER_PASSWORD. Секреты храните в настройках Render, не в Git.

При подключении своего домена добавьте его HTTPS origin в WEB_ORIGINS. Не используйте демонстрационный seed в production.

Бесплатная база Render имеет ограниченный срок работы. До указанной в Dashboard даты истечения перенесите данные или смените тариф; приложение не заменяет резервные копии.
