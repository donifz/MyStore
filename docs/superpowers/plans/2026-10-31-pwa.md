# MyStore PWA Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for inline execution.

**Goal:** Install MyStore as an app icon opening the role-aware workspace.
**Architecture:** Static manifest/icons in Vite public assets, served by Express;
one React provider retains the install prompt across navigation and one shared
install control shows native installation or browser instructions.
**Tech Stack:** Existing React, Vite, Express, Vitest and Playwright.
**Spec:** `docs/superpowers/specs/2026-10-31-pwa-design.md`

## Global Constraints

No new dependency, service worker, API caching, offline mutation or auto-reload.
Start URL `/seller`, scope `/`, standalone display. Keep financial flows intact.

## Review Focus

Cancellation/rejection must leave menu instructions available; appinstalled and
standalone mode hide controls; prompt survives route changes; production serves
manifest and PNGs rather than SPA HTML; narrow login/sidebar must not overflow.
